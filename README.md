# Student Performance Analysis using NumPy

## 📌 Project Overview
This project analyzes student marks using NumPy arrays to derive meaningful insights such as average performance, topper identification, grading, and pass/fail statistics.

## 🛠 Technologies Used
- Python
- NumPy

## 📊 Features
- 2D NumPy array for student marks
- Row-wise and column-wise analysis
- Student and subject averages
- Topper and weakest student detection
- Grade assignment using NumPy conditional operations
- Clean design without excessive print statements

## 🧠 Concepts Applied
- Array creation and slicing
- `axis` based operations
- `mean`, `argmax`, `argmin`
- Boolean filtering
- `np.where` for grading

## 🚀 What I Learned
- Practical usage of NumPy for data analysis
- How to think in arrays instead of loops
- Writing clean and readable analytical code
